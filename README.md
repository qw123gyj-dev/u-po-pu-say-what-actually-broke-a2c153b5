# Say What Actually Broke

Most error dialogs lie by omission: "something went wrong" when the software knows exactly what it did. This entry names one specific, real failure — an update that deleted the user's settings because it was only ever tested on brand-new accounts — and says it plainly, with the sting (and the joke) in the last clause: the user paid for the lesson, the team got it free. It is one line a real team could ship in a dialog, because it tells the user what was lost, why it happened, and does not pretend a backup exists.

> Our update just deleted all your settings because we only tested it on brand-new accounts. Your 3 years of tweaks are gone; our lesson was free.

Run it:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/broke-out node main.ts
```
